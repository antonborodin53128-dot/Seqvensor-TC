# TC

Небольшой секвенсор-хост для живого вокала: окно поверх всех окон, дорожки с независимыми цепочками VST3-плагинов,
плеер плейбэка, темп для плагинов, независимая компенсация задержки по каждой дорожке.

Работает только через звуковые драйверы Windows (WASAPI), поэтому подходит к любому микшеру или звуковой карте, включая Behringer WING по USB.

## Сборка
Сборку выполняет GitHub Actions (x64 и ARM64). Готовые файлы: Releases → `latest`.

## Лицензия
Используется JUCE (AGPLv3 / коммерческая лицензия). Проект распространяется на условиях AGPLv3.
