# TC — передача проекта в другой чат

Репозиторий: https://github.com/antonborodin53128-dot/Seqvensor-TC (ветка `main`)
Сборки: GitHub Actions → релиз `latest` (файлы `TC-x64.exe`, `TC-arm64.exe`). Каждый push в main собирает оба.

## Что это
TC — стабильный мини-секвенсор / VST3-хост для Windows (x64 + ARM64), всегда поверх окон. Нужен для живого мониторинга вокала через любой аудиодрайвер. Железо пользователя: Behringer WING Rack + S32.
Стек: JUCE 8.0.12, C++17, CMake FetchContent, VST3.

## Что уже есть
- Независимая цепочка плагинов на каждой дорожке (5 слотов), темп передаётся плагинам, метроном на дорожку, отсчёт 4 доли перед тактом 1, общий транспорт (Play / Pause / Stop).
- Горизонтальный таймлайн с аудиоклипами (как в Pro Tools): правый клик по клипу, повтор, привязка к сетке, замена файла, определение темпа (только показывает, темп проекта не меняет).
- Выделение клипов: клик, Shift (диапазон по дорожкам), Ctrl (добавить/убрать), рамка мышкой в пустой области, Ctrl+A, Delete, Esc, пробел = play/pause. Группа двигается вместе; меню действует на группу.
- Клип при перетаскивании файла всегда на такте 1; каждый следующий файл — новая дорожка без входа.
- Индикатор уровня — до фейдера (не зависит от положения фейдера).
- Иерархия: Секвенция (группа/проект) → Плейлисты + Треки (композиции). Три вкладки слева: Seq / Playlist / Tracks. Справа плашка «сейчас играет» (текущий трек + приглушённо следующий), крупные кнопки назад/вперёд по бокам. Play/Pause/Stop в верхней строке.
- Правила: плейлист нельзя создать без секвенции, трек — без плейлиста; «осиротевшие» треки автоматически попадают в текущий плейлист.
- Соседние треки плейлиста подгружаются заранее (переключение мгновенное).
- Стиль: чисто чёрный фон (OLED), янтарный акцент #FFA81F, спокойно-зелёные клипы, скруглённые квадратные кнопки, меню в стиле Apple, плавная прокрутка волны (VBlank + экстраполяция часов).
- Хранение: `%APPDATA%\TC\Projects\<секвенция>\Compositions\*.xml`, `...\Playlists\*.xml`, `session.xml`. Данные на каждом ПК свои.
- Тестовые мультитреки (3 песни: ударные, гитары, вокал, бас) — `D:\WING\Multitracks\`.

## Архитектура (Source/)
Engine (аудио-движок, глобальные часы в аудиопотоке, кэш секвенций), Track (цепочка плагинов, клипы, метроном, пики), Clip, Timeline (TimelineView + LaneComponent: отрисовка, выделение, drag), TrackComponent (заголовок дорожки, иконки, метры), PlayerBar (вкладки/список/плашка), MainComponent (всё управление), Library.h (папки, плейлисты, сессия), Style.h (палитра `Pal` + LookAndFeel), TempoDetect.
Правила кода: русские строки только через `"..."_ru`; никогда `String::formatted` с кириллицей.

## Известные особенности и риски
- Всё последнее (вкладки, выделение, рамка, drop на такт 1, пре-фейдерный метр, правила плейлистов) собрано, но в самой Windows-программе мной не запускалось — тестирует пользователь. Последний исправленный баг: вылет при выборе трека из списка (use-after-free на ссылке в `switchToSequence`).
- ARM64-exe иногда занят (запущен) — тогда записывать как `TC-arm64-new.exe`.
- Песочница Claude: Windows-приложение запустить нельзя, пакеты apt/pypi недоступны, `gh release download` не работает (GraphQL закрыт) — скачивать через `gh api repos/.../releases/assets/<id>` с `Accept: application/octet-stream`.
- Доставка на ПК: через мост устройства (`device_commit_files`); после записи проверять размер файлов — один раз запись не доходила.

## Бэклог
1. Автоопределение темпа и тональности с настройкой исходных каналов (иконка шестерёнки пока заглушка).
2. Многоканальная запись (REC пока только флаг).
3. Пульт с телефона.
4. Песочница для плагинов (чтобы падение плагина не роняло программу).
5. Опция ASIO.
6. Проверить на реальном железе WING: задержки, входы по умолчанию, работа без выбранного входа.

## Предпочтения пользователя
Видеомонтажёр, русский язык. Сам использовать все инструменты, плагины, навыки без напоминаний; разрешение спрашивать только перед скачиванием/установкой нового. Для монтажных задач сначала загружать навык `montazh-instrumenty`. Отвечать кратко, без пересказа шагов.

## Цикл работы
правка → проверка `g++ -fsyntax-only` → `git commit` + `git push origin main` → ждать CI (`gh run list --limit 1`) → скачать exe через REST → записать в папку пользователя (`D:\WING\TC-x64.exe`, `TC-arm64.exe`) и проверить размер.
